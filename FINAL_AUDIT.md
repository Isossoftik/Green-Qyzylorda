## FIXED

- **Сетевой доступ к деморолям.** Команды `dev` и `start` в `package.json` теперь слушают `127.0.0.1`. `src/proxy.ts` отклоняет посторонний Host для страниц и API. Проверен HTTP 403 с явно подставленным внешним Host. Настройки объясняют свободный выбор роли. Стенд предназначен для запуска непосредственно на демонстрационном компьютере.
- **Размер тела и ошибки формы.** Три обработчика `src/app/api/{workflow,green,analysis}/route.ts` используют `src/lib/request-form.ts`. Потоковый запрос без Content-Length размером 7 МиБ получил 413. Чужой Origin и Origin null получили 403, повреждённая форма — 400. Регрессии находятся в `tests/lifecycle.test.mjs`.
- **Фотографии истории.** При замене фотографии дерева сохраняется файл, на который ссылается решение оператора. GET фотографии учитывает эту связь и проверяет фактический путь. Незавершённая запись изображения получает временное имя, готовый файл публикуется переименованием. Изменены `src/lib/green-mutations.ts`, `src/lib/mutations.ts`, `src/app/api/photos/[name]/route.ts`, `tests/green-cycle.mjs`.
- **Резервное копирование.** `scripts/backup.py` использует SQLite Online Backup API, на время снимка базы и копирования файлов удерживает блокировку писателей. В снимок попадают зафиксированные данные WAL. Проверяются integrity_check, foreign_key_check, наличие фотографий, включая историю решений, и SHA-256 базы и файлов. Готовая копия публикуется после проверки. Восстановление разрешено в новую папку. `tests/backup_test.py` проверил запись, находившуюся в WAL, восстановление, отказ перезаписи и отказ при испорченной контрольной сумме.
- **Мобильная карточка.** Длинное название созданного дерева вызвало горизонтальное переполнение при 390 px. Исправлены переносы пользовательского текста и минимальные размеры элементов в `src/app/urban.css`. Повторно проверена карточка с длинным названием.

### Как повторить резервирование и восстановление

Из корня проекта, Python 3.11+ и PowerShell:

```powershell
npm run backup
# Подставьте имя выведенной папки снимка и новый путь назначения.
py -3 scripts/backup.py --restore ".tools/backups/ИМЯ-СНИМКА" --to ".tools/restore-check"
py -3 -B tests/backup_test.py
```

Фактический снимок аудита — `.tools/backups/20261114-024953-eeb54e17`. Проверенное восстановление — `.tools/audit/restore-024953`. Восстановленная папка содержит `prisma/demo.db`, `uploads` и манифест. Во время копирования большого архива операции записи в приложении могут ожидать блокировку. Для защиты от отказа диска храните дополнительную копию на другом носителе с ограниченным доступом.
