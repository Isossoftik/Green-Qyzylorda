# Локальное компьютерное зрение

Рабочая конфигурация проверена на Windows 11 x64 с Python 3.14.0 и Node.js 24. ONNX Runtime использует CPUExecutionProvider и три вычислительных потока. Веса и токенизатор читаются с диска при первом обращении к модели. Один процесс Next.js обслуживает один Python-процесс инференса. Одновременный второй запрос на анализ получает сообщение о занятости.

## Установка на другой компьютер

Из корня проекта в PowerShell выполните команды ниже. Для уже работающего стенда зависимости приложения и базу повторно готовить не требуется.

```powershell
py -3.14 -m venv .tools/vision-env
& ./.tools/vision-env/Scripts/python.exe -m pip install -r scripts/vision-requirements.txt
& ./.tools/vision-env/Scripts/python.exe scripts/setup-vision.py
$env:GREEN_VISION_PYTHON = (Resolve-Path .tools/vision-env/Scripts/python.exe).Path
npm run dev -- --hostname 127.0.0.1
```

На новой установке приложения сначала выполните `npm ci` и `npm run db:setup`. На этом ноутбуке npm доступен после `$env:Path = "$PWD/.tools/runtime;$env:Path"`. Настройку GREEN_VISION_PYTHON можно сохранить в файле .env.local. Укажите абсолютный путь к интерпретатору, в котором установлены зависимости. В Linux используйте Python из bin/python виртуального окружения. Скрипт загрузки использует curl и повторно использует файлы с верной SHA-256. Для полностью автономного запуска скопируйте подготовленную папку .tools/vision и установите зависимости из локальных колёс.

Веса ONNX и оригинальный токенизатор взяты из Xenova/clip-vit-base-patch32, ревизия 6b7c523703ae26e39be4b03774966f8571c7f523. Лицензия MIT приведена в scripts/CLIP-LICENSE.txt. Веса занимают 153 695 702 байта, токенизатор — 2 224 119 байт. [Карточка модели](https://huggingface.co/Xenova/clip-vit-base-patch32/tree/6b7c523703ae26e39be4b03774966f8571c7f523)

## Проверка на стенде

Откройте /ai-workspace с DEMO ROLE «Оператор», выберите обращение и прикрепите разрешённый для этого обращения снимок. Кнопка «Анализировать фото» запускает локальный процесс. Для дерева с фотографией доступна та же функция в карточке дерева и в разделе фотографий деревьев. История сохраняет модель и ревизию, исходную категорию и ручные оценки отдельными строками ReviewDecision. База и каталог uploads сохраняют существующую структуру.

Работающий процесс держит одну сессию модели. Время ожидания загрузки и обработки по умолчанию составляет по 30 секунд. GREEN_VISION_TIMEOUT_MS настраивает лимит инференса в диапазоне 1–60000 мс. После тайм-аута сервер завершает процесс и при следующем запросе заново проверяет веса. Отсутствующие или несовместимые веса переводят интерфейс в состояние «AI не настроен». Ошибка после прикрепления сохраняет фотографию в обращении для повторной попытки.

## Воспроизведение измерения

```powershell
& ./.tools/vision-env/Scripts/python.exe scripts/evaluate-vision.py
npm run typecheck
npm run build
npm test
```

Набор tests/vision-data содержит десять фотографий Wikimedia Commons, по две на категорию. Файлы, исходные страницы, авторы, индивидуальные лицензии, ссылки на условия использования и SHA-256 зафиксированы в manifest.json до первого инференса. Использованы уменьшенные копии Commons. Метки заданы по описанию фотографий. Для озеленения взяты изношенный газон и вытоптанная тропа, для неопределённой проблемы — две фотографии кошек. Пять англоязычных подсказок зафиксированы в scripts/local-vision.py. Таблица по каждому файлу находится в results.json. Порядок индексов — засохшее дерево, повреждение дерева, мусор на территории, проблема озеленения, неопределённая проблема.

Accuracy на этом наборе составила 5/10. Выборка мала, содержит всего два отрицательных примера одного типа и не представляет городские обращения Кызылорды. Для неизвестного сюжета CLIP всё равно выбирает ближайшую из пяти подписей. Отказ от классификации по калиброванному порогу ещё не реализован. Оператор проверяет результат. Для диагностики заболеваний нужен осмотр специалистом.
